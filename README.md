# ShootingGalleryVR_IvanVelaFerrando

1. Objective

VR shooting gallery where destroying targets must be done to win under a stablished period of time. If you fail, simply shoot the restart floating button to repeat.

2. Controls
   
Grab weapon (XR grab)
Shoot (trigger)
Teleport (ray)
Move (joystick)

3. Features implemented
Weapons (pistol + shotgun)
Projectile system
Targets + scoring
UI system
VR locomotion

4. How to run
Open build
Start scene - Main Menu - Start
Use VR controllers / simulator
